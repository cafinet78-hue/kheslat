# 🎮 GTA VI Shorts Bot

ربات خودکار برای ساخت شورت و ویدیوی بلند از استریم‌های **GTA VI** و آپلود روی یوتیوب.

## این برنامه چی‌کار می‌کنه؟

```
 پیدا کردن استریم لایو GTA VI  (Kick / Twitch / YouTube)
            ↓
 ضبط استریم + ضبط چت (تکه‌های ۱ دقیقه‌ای)
            ↓
 هر ۲۰ دقیقه: پیدا کردن لحظه‌های هیجانی
   (صدای بلند + شلوغ شدن یهویی چت)
            ↓
 Claude تصویرها، حرف‌ها و چت رو می‌بینه → بهترین لحظه‌ها رو انتخاب می‌کنه
   و تایتل، توضیحات، هشتگ و متن کاور رو می‌نویسه
            ↓
 ادیت خودکار:  گیم‌پلی بالا ▸ ویدیوی خودت پایین ▸ زیرنویس ▸ متن هوک ▸ اسم استریمر
            ↓
 ساخت کاور (تامبنیل)
            ↓
 وقتی استریم تموم شد → ویدیوی بلند (Compilation) با چپترها
            ↓
 آپلود خودکار روی یوتیوب (با رعایت سقف آپلود روزانه)
```

از هر استریم حداکثر ۵ شورت **۳۰ ثانیه تا ۲ دقیقه‌ای** (یوتیوب شورت‌های تا ۳ دقیقه رو قبول می‌کنه) + یک ویدیوی بلند ساخته می‌شه.

---

## نصب (ویندوز)

۱. این پوشه رو دانلود کن (روی GitHub دکمه سبز **Code** و بعد **Download ZIP**) و از حالت فشرده درش بیار.

۲. **ویدیوی خودت** (مثلاً ۱ تا ۲ دقیقه که پشت کامپیوتر نشستی و داری بازی می‌کنی) رو بذار توی پوشه **`assets`**. اسمش مهم نیست. اگه چند تا ویدیو بذاری، برنامه بین‌شون می‌چرخه.

۳. روی **`install_windows.bat`** دابل‌کلیک کن.
   - اگه Python یا FFmpeg نداشته باشی، خودش نصبشون می‌کنه. بعدش پنجره رو ببند و **دوباره** همین فایل رو اجرا کن.
   - بعد بقیه پکیج‌ها رو نصب می‌کنه و چند تا سوال می‌پرسه:
     - استریمرها، مثلا: `kick:xqc, twitch:summit1g, youtube:@SomeChannel`
     - کلید Claude

> مک/لینوکس: `./install.sh`

## چیزهایی که باید بهش بدی

| چی | از کجا | لازمه؟ |
|---|---|---|
| **ویدیوی خودت** (فیس‌کم / ری‌اکشن) | بذارش توی پوشه `assets`. اگه از کلیپ کوتاه‌تر باشه تکرار می‌شه | بله |
| **کلید Claude** (`ANTHROPIC_API_KEY`) | [console.anthropic.com](https://console.anthropic.com) ← API Keys | خیلی توصیه می‌شه (بدونش تایتل‌ها ساده می‌شن) |
| **client_secret.json** (یوتیوب) | مراحل پایین | برای آپلود خودکار |
| Twitch Client ID/Secret | [dev.twitch.tv/console](https://dev.twitch.tv/console) | اختیاری: پیدا کردن خودکار استریمرهای توییچ |
| Kick Client ID/Secret | تنظیمات حساب Kick ← Developer | اختیاری: پیدا کردن خودکار استریمرهای کیک |

کلیدها توی فایل `.env` ذخیره می‌شن.

## وصل کردن یوتیوب

۱. برو [console.cloud.google.com](https://console.cloud.google.com) و یه Project جدید بساز.
۲. **APIs & Services → Library** ← `YouTube Data API v3` رو پیدا کن و **Enable** کن.
۳. **OAuth consent screen**: نوع External، اسم برنامه هر چی خواستی، ایمیل خودت. توی **Test users** ایمیل اکانت یوتیوبت رو اضافه کن. بعد **Publish App** رو بزن (اگه نزنی، هر ۷ روز باید دوباره لاگین کنی).
۴. **Credentials → Create Credentials → OAuth client ID** ← نوع **Desktop app** ← فایل JSON رو دانلود کن، اسمش رو بذار `client_secret.json` و بذارش کنار همین README.
۵. روی **`youtube_login.bat`** دابل‌کلیک کن. مرورگر باز می‌شه، با اکانت یوتیوبت وارد شو و اجازه بده.

> ⚠️ **خیلی مهم:** یوتیوب ویدیوهایی که با یک پروژه API «تأییدنشده» آپلود می‌شن رو **Private قفل می‌کنه**. برای اینکه ویدیوها Public بشن، فرم رایگان [YouTube API Audit](https://support.google.com/youtube/contact/yt_api_form) رو پر کن. تا وقتی تأیید بشه، ویدیوها آپلود می‌شن ولی باید خودت توی YouTube Studio دستی Public کنی.
>
> سهمیه پیش‌فرض API یوتیوب حدود **۶ آپلود در روز** است. برنامه خودش رعایتش می‌کنه و بقیه رو برای روز بعد نگه می‌داره.
>
> برای کاور اختصاصی، کانالت باید در [youtube.com/verify](https://www.youtube.com/verify) تأیید شماره تلفن شده باشه.

## اجرا

روی **`run.bat`** دابل‌کلیک کن. همین! تا وقتی پنجره بازه کار می‌کنه:
- هر ۵ دقیقه دنبال استریم لایو GTA VI می‌گرده
- ضبط می‌کنه، تحلیل می‌کنه، ادیت می‌کنه و آپلود می‌کنه
- همه ویدیوها توی پوشه `data/output` ذخیره می‌شن

### دستورهای دیگه (توی CMD داخل پوشه برنامه)

```bat
venv\Scripts\python -m gtabot doctor           :: چک کردن اینکه همه چی درسته
venv\Scripts\python -m gtabot status           :: لیست ویدیوهای ساخته‌شده و آپلودشده
venv\Scripts\python -m gtabot process "https://www.twitch.tv/videos/123456"   :: ساخت شورت از یه ویدیوی ضبط‌شده (برای تست عالیه)
venv\Scripts\python -m gtabot process "C:\Videos\gta.mp4" --channel xqc       :: از فایل خودت
venv\Scripts\python -m gtabot upload           :: آپلود فوری ویدیوی بعدی
```

**پیشنهاد:** اول با `process` روی یه ویدیوی ضبط‌شده تست کن و خروجی‌ها رو توی `data/output` ببین. بعد `run` رو بزن.

## تنظیمات (`config.yaml`)

مهم‌ترین‌ها:

| تنظیم | توضیح |
|---|---|
| `watch` | لیست استریمرها |
| `auto_discover` | پیدا کردن خودکار پربیننده‌ترین استریم‌های GTA VI |
| `max_clips_per_stream` | چند شورت از هر استریم (پیش‌فرض ۵) |
| `layout.top_ratio` | چند درصد صفحه گیم‌پلی باشه (پیش‌فرض ۰.۶) |
| `facecam_volume` | صدای ویدیوی خودت (۰ = بی‌صدا) |
| `content_language` | زبان تایتل‌ها (`English` برای مخاطب جهانی، `Persian` برای فارسی) |
| `channel_style` | سبک کانالت، Claude بر اساسش تایتل می‌نویسه |
| `youtube.privacy` | `public` / `unlisted` / `private` |
| `whisper_model` | دقت زیرنویس (`small` پیش‌فرض؛ اگه کامپیوترت کنده `base` بذار) |

## سیستم مورد نیاز

- ویندوز ۱۰/۱۱ (یا مک/لینوکس)
- اینترنت خوب: هر استریم 720p حدود ۳ تا ۵ مگابیت دانلود می‌خواد
- فضای خالی: حدود ۲ گیگ برای هر ساعت ضبط (بعد از تحلیل پاک می‌شه)
- CPU معمولی کافیه؛ کارت گرافیک NVIDIA زیرنویس رو سریع‌تر می‌کنه
- هزینه Claude: حدود ۳ سنت برای هر ۲۰ دقیقه استریم

## ⚖️ کپی‌رایت: حتما بخون

**هیچ تایتل یا ترفندی جلوی تشخیص کپی‌رایت یوتیوب (Content ID) رو نمی‌گیره.** یوتیوب خود تصویر و صدا رو مقایسه می‌کنه، نه تایتل رو. چیزی که واقعاً کانال رو امن نگه می‌داره:

- **اجازه از استریمر.** مهم‌ترین قدم همینه. خیلی از استریمرهای Kick و Twitch به کلیپرها اجازه می‌دن، و بعضی‌هاشون برنامه رسمی کلیپ هم دارن. یه پیام کوتاه بفرست و بپرس.
- **محتوای جدید واقعی.** ویدیوی خودت پایین صفحه، زیرنویس، متن هوک و انتخاب بهترین لحظه‌ها همین الان اضافه می‌شه. هر چی ری‌اکشن خودت واقعی‌تر باشه (حرف بزنی، واکنش نشون بدی)، ویدیو بیشتر «محتوای جدید» حساب می‌شه. برای همین بهتره چند تا ویدیوی مختلف از خودت توی `assets` بذاری و `facecam_volume` رو بالا ببری، که صدای خودت هم شنیده بشه.
- **اسم و لینک استریمر** خودکار روی ویدیو و توی توضیحات میاد. خاموشش نکن. هم درسته و هم استریمرها معمولاً از کلیپرهایی که اسمشون رو می‌ذارن استقبال می‌کنن.
- برای کسب درآمد، یوتیوب محتوای «Reused» بدون ارزش افزوده رو قبول نمی‌کنه. ری‌اکشن و صدای خودت اینجا خیلی کمک می‌کنه.
