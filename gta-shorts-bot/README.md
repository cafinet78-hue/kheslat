# 🎮 GTA 6 Shorts Bot

لینک یه ویدیوی GTA 6 (یوتیوب، توییچ یا کیک) رو بهش می‌دی. خودش **بهترین لحظه‌ها رو پیدا می‌کنه**، **ویدیوی خودت رو زیرش می‌ذاره**، زیرنویس و متن جذاب و کاور می‌سازه و **یکی‌یکی روی یوتیوبت آپلود می‌کنه**.
می‌تونه استریمرهای کیک و توییچ رو هم وقتی لایو هستن خودش ضبط کنه.

```
لینک ویدیو  →  دانلود  →  پیدا کردن لحظه‌های هیجانی (صدا + چت + Claude)
            →  ادیت: گیم‌پلی بالا / ویدیوی تو پایین / زیرنویس / متن هوک / اسم استریمر
            →  کاور + تایتل + توضیحات + هشتگ
            →  آپلود یکی‌یکی روی یوتیوب
```

هر شورت **۳۰ ثانیه تا ۲ دقیقه** است. از هر ویدیو حداکثر ۵ شورت ساخته می‌شه، به‌اضافه یه ویدیوی بلند (Compilation).

---

## 🖥 نصب روی کامپیوتر (ویندوز)، فقط یک بار

۱. **فایل زیپ رو از حالت فشرده دربیار**: راست‌کلیک ← **Extract All**.

۲. ویدیوی خودت از قبل توی پوشه **`assets`** هست. اگه خواستی ویدیوی دیگه‌ای هم بذاری، بندازش همون‌جا. اگه چند تا ویدیو باشه، برنامه بین‌شون می‌چرخه.

۳. روی **`install_windows.bat`** دابل‌کلیک کن.
   - اگه ویندوز پیغام آبی داد: **More info** ← **Run anyway**.
   - اگه Python یا FFmpeg رو نصب کرد و گفت پنجره رو ببند، ببند و **دوباره** روی همین فایل دابل‌کلیک کن.
   - نصب ۵ تا ۱۰ دقیقه طول می‌کشه. آخرش **صفحه کنترل** خودش توی مرورگر باز می‌شه.

> اگه نصب گیر کرد یا ارور داد، VPN رو روشن کن و دوباره اجرا کن.

## ▶️ استفاده (هر بار)

۱. روی **`START.bat`** دابل‌کلیک کن. صفحه کنترل باز می‌شه (آدرسش `http://localhost:8080` هست). پنجره سیاه رو **نبند**، فقط کوچیکش کن.

۲. توی کادر زرد بالای صفحه، **لینک ویدیوی GTA 6** رو بذار و **🎬 ساخت شورت** رو بزن.

۳. صبر کن. شورت‌ها پایین صفحه میان و همون‌جا می‌تونی ببینیشون. فایل‌ها توی پوشه `data\output` هم ذخیره می‌شن.

۴. اگه یوتیوب وصل باشه، هر یک ساعت یکی آپلود می‌شه. هر کدوم رو نخوای آپلود بشه، زیرش **«آپلود نشه ✖»** رو بزن.

**ضبط خودکار استریم‌های لایو:** اسم استریمرها رو توی بخش تنظیمات بنویس (مثلاً `kick:xqc`)، بعد دکمه **▶️ روشن کردن ربات** رو بزن.

## 📺 وصل کردن یوتیوب (فقط یک بار)

این صفحه‌ها رو باز کن. اگه باز نشدن، VPN رو روشن کن.

۱. **پروژه بساز**: یه اسم بزن (مثلاً `gta bot`) و **Create** رو بزن.
   https://console.cloud.google.com/projectcreate
۲. **API یوتیوب رو روشن کن**: **Enable** رو بزن.
   https://console.cloud.google.com/apis/library/youtube.googleapis.com
۳. **صفحه اجازه**: **Get started** ← اسم و ایمیلت ← **External** ← تا آخر **Next** و **Create**.
   https://console.cloud.google.com/auth/overview
۴. **ایمیل یوتیوبت رو اضافه کن**: **Add users** ← ایمیلی که باهاش وارد یوتیوب می‌شی ← **Save**.
   https://console.cloud.google.com/auth/audience
۵. **فایل کلید**: نوع **Desktop app** ← **Create** ← **Download JSON**.
   https://console.cloud.google.com/auth/clients/create
۶. توی صفحه کنترل، بخش **📺 اتصال یوتیوب**: فایل JSON رو انتخاب کن ← **آپلود فایل** ← **اتصال به یوتیوب** ← توی صفحه گوگل وارد شو و **Continue / Allow** رو بزن.
   اگه گوگل گفت «Google hasn't verified this app»، روی **Continue** بزن. چون خودت سازنده‌شی، مشکلی نیست.

> ⚠️ **تا وقتی یوتیوب پروژه‌ات رو تأیید نکرده**، ویدیوهایی که با برنامه آپلود می‌شن **Private** می‌مونن. برای Public شدن، این فرم رایگان رو پر کن:
> https://support.google.com/youtube/contact/yt_api_form
> تا تأیید بشه، می‌تونی ویدیوها رو توی YouTube Studio دستی Public کنی.
>
> یوتیوب از این روش روزی حدود **۶ آپلود** اجازه می‌ده. برنامه بقیه رو برای روز بعد نگه می‌داره.

## 🤖 Claude (اختیاری، ولی نتیجه خیلی بهتر می‌شه)

با Claude، لحظه‌ها با دیدن تصویر، شنیدن حرف‌ها و خوندن چت انتخاب می‌شن و تایتل و توضیحات هر ویدیو هم مخصوص خودش نوشته می‌شه. بدون Claude هم برنامه کار می‌کنه، ولی تایتل‌ها از یه لیست آماده انتخاب می‌شن.

- **با کلید API:** از https://console.anthropic.com/settings/keys یه کلید بساز و توی صفحه کنترل، بخش تنظیمات، بذارش.
- **با اشتراک Claude Pro:** روی **`claude_pro_login.bat`** دابل‌کلیک کن. با اکانت Pro وارد شو، توکنی که نشون می‌ده رو کپی کن و توی همون پنجره Paste کن. بعد `START.bat` رو ببند و دوباره باز کن.

## ⚖️ کپی‌رایت: حتما بخون

**هیچ ترفندی جلوی سیستم کپی‌رایت یوتیوب (Content ID) رو نمی‌گیره.** یوتیوب خود تصویر و صدا رو مقایسه می‌کنه، و دور زدنش هم ریسک استرایک و بسته شدن کانال رو داره. چیزی که واقعاً کانال رو امن نگه می‌داره:

- **اجازه از استریمر.** مهم‌ترین قدم همینه. خیلی از استریمرها به کلیپرها اجازه می‌دن. یه پیام کوتاه بفرست و بپرس.
- **محتوای جدید واقعی.** ویدیوی تو پایین صفحه، زیرنویس، متن هوک و انتخاب بهترین لحظه‌ها خودکار اضافه می‌شه. هر چی ری‌اکشن خودت واقعی‌تر باشه (حرف بزنی، واکنش نشون بدی)، ویدیو بیشتر «محتوای جدید» حساب می‌شه و کمتر خطر «Reused content» داره. توی تنظیمات **صدای ویدیوی خودت** رو بالا ببر تا صدات شنیده بشه.
- **اسم و لینک استریمر** خودکار روی ویدیو و توی توضیحات میاد. خاموشش نکن.

## سیستم مورد نیاز

- ویندوز ۱۰ یا ۱۱، اینترنت معمولی، حدود ۱۰ گیگ فضای خالی
- CPU معمولی کافیه. با کارت گرافیک NVIDIA، زیرنویس سریع‌تر ساخته می‌شه.

## رفع مشکل

- لاگ کامل برنامه پایین صفحه کنترل هست (بخش 📜 گزارش)، و توی فایل `data\bot.log`.
- اگه دانلود یا آپلود کار نکرد، VPN رو روشن کن.
- اگه صفحه کنترل باز نشد، مطمئن شو پنجره سیاه `START.bat` بازه، بعد این آدرس رو توی مرورگر بزن: `http://localhost:8080`
- اگه این پوشه رو توی **Claude Code** باز کنی، فایل `CLAUDE.md` بهش توضیح می‌ده برنامه چطور کار می‌کنه و می‌تونه درستش کنه.
